# Part 2 - Indexing and Evaluation

This part builds an inverted index for the fashion product collection, retrieves products using conjunctive queries, and ranks the results using TF-IDF. It also evaluates the results using supplied and manually assigned relevance labels. The implementation is in [build_index.ipynb](build_index.ipynb).

In the [report](IRWA-2026-u212910-u103898-u231623-part-2.pdf) we explain in detail how the index and ranking functions work, present the evaluation results, and discuss the system’s main limitations and possible improvements.

## To reproduce the results

1. **Set up the environment**

```bash
# Create and activate a virtual environment
python -m venv .venv
source .venv/bin/activate

# Install required packages
python -m pip install pip install -r requirements.txt
```

2. **Make sure the required input files are inside `data/`before running the notebook**:
- fashion_products.csv
- index_info.csv
- validation_labels.csv
The first two files are generated by running [preprocessing.ipynb](../part_1/preprocessing.ipynb), as explained in the [Part 1 README](../part_1/README.md).

3. **Open and run [build_index.ipynb](build_index.ipynb)**
Use project_progress/part_2/ as the notebook’s working directory so that the ../../data/ paths resolve correctly. Run the cells in order.

Running the notebook builds the inverted index and computes TF-IDF statistics in memory. These objects are used for retrieval and ranking but are not exported to disk. The notebook also exports the test-query results to data/test_queries_results.csv if that file does not already exist.
