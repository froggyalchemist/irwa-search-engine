# Part 3 - Ranking & Filtering

In this part, we implement and compare different ranking approaches. These include TF-IDF + cosine similarity, BM25, our own custom score and Word2Vec. We compare the three first approaches using the five test queries defined in Part 2 and measuring the NDGC@20 for each of them. We discuss the performance of Word2Vec qualitatively in the report. The implementation is in [ranking_filtering.ipynb](ranking_filtering.ipynb).

In the [report](IRWA-2026-u212910-u103898-u231623-part-3.pdf) we explain in detail the implementation of the four strategies, the results of our evaluation and discuss alternative representations of documents.

## To reproduce the results

1. **Set up the environment**

```bash
# Create and activate a virtual environment
python -m venv .venv
source .venv/bin/activate

# Install required packages
python -m pip install pip install -r requirements.txt
```

2. **Make sure the required input files are inside `data/`before running the notebook**:
- `fashion_products.csv`
- `index_info.csv`
- `test_queries_pool_labels.csv`

The first two files are generated by running [preprocessing.ipynb](../part_1/preprocessing.ipynb), as explained in the [Part 1 README](../part_1/README.md).

3. **Open and run [ranking_filtering.ipynb](ranking_filtering.ipynb)**

Use project_progress/part_3/ as the notebook’s working directory so that the ../../data/ paths resolve correctly. Run the cells in order.
